# QuantSectionTitle

Compact section marker with signal accent color.

## Installation

```bash
npx @quanty-ui/cli add section-title
```

## Props

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `as` | `'h2' \| 'h3' \| 'h4' \| 'p'` | `'h2'` | Rendered element |

## Usage

```vue
<QuantSectionTitle as="h3">Risk Controls</QuantSectionTitle>
```
