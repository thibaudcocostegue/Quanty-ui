# QuantAppHeader

Product identity header with strict structure emphasis.

## Installation

```bash
npx @quanty-ui/cli add app-header
```

## Props

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `title` | `string` | — | Main header title |
| `subtitle` | `string` | `''` | Secondary context |

## Usage

```vue
<QuantAppHeader title="Trading Console" subtitle="Live environment" />
```
